# FASE 1 — VERIFICA COM6

Prima controlla:

- COM6 esistente;
- dispositivo associato;
- porta utilizzabile da PlatformIO;
- eventuale porta occupata da un altro processo.

Se COM6 è disponibile, utilizzala esplicitamente per l'upload e per il monitor seriale.

Se l'upload fallisce perché la porta è occupata:

1. individua il processo che la sta utilizzando;
2. chiudi il monitor seriale precedente;
3. riprova;
4. NON modificare il codice per aggirare il problema.

---

# FASE 2 — BUILD

Esegui:

```text
platformio run
```

Se fallisce:

- correggi SOLO gli errori necessari;
- ricompila;
- non procedere con un firmware che non compila.

Se compila, procedi immediatamente all'upload.

---

# FASE 3 — UPLOAD REALE

Esegui l'upload sulla:

`COM6`

Dopo l'upload verifica che termini correttamente.

Se l'upload fallisce:

- raccogli l'errore completo;
- verifica baud rate;
- verifica porta;
- verifica reset/bootloader;
- riprova una volta;
- non modificare il firmware per problemi di connessione USB.

---

# FASE 4 — SERIAL MONITOR

Apri il monitor seriale sulla COM6.

Usa il baud rate configurato dal progetto/PlatformIO.

Dopo aver aperto il monitor:

1. resetta l'ESP8266;
2. acquisisci l'intero log di boot;
3. attendi che il dispositivo completi l'inizializzazione;
4. non interrompere il processo troppo presto.

Cerca esplicitamente:

- boot;
- reset reason;
- watchdog;
- crash;
- exception;
- heap;
- inizializzazione Wi-Fi;
- modalità Wi-Fi;
- SoftAP;
- SSID;
- IP;
- DHCP;
- eventuali errori.

# FASE 5 — DEBUG PRIORITARIO DEL SOFTAP

Questo è il problema principale.

Nel codice individua esattamente dove viene inizializzato il SoftAP.

Cerca tutte le chiamate relative a:

```cpp
WiFi.mode(...)
WiFi.softAP(...)
WiFi.softAPConfig(...)
WiFi.disconnect(...)
WiFi.begin(...)
```

e tutte le funzioni che possono modificare la modalità Wi-Fi dopo l'avvio.

Devi ricostruire il flusso completo:

```text
BOOT
 ↓
inizializzazione Wi-Fi
 ↓
WiFi.mode(...)
 ↓
configurazione AP
 ↓
WiFi.softAP(...)
 ↓
eventuale configurazione IP
 ↓
altri moduli
 ↓
LOOP
```

Determina se il SoftAP:

1. viene effettivamente inizializzato;
2. viene inizializzato con successo;
3. riceve l'SSID corretto;
4. rimane attivo;
5. viene successivamente disabilitato/modificato da qualche altra parte del firmware.
